- Remove old #Linux #kernel using the [[Update Manager]]. You should go to preferences and consider to enable automatic kernel removals. In the #terminal consider these
- [Guide by Gemini](https://gemini.google.com/share/7f7895f502f5)
-
- Find out on which kernel you are currently running
  ```
  uname -r
  ```
  
  List all kernels
  ```
  dpkg --list | grep linux-image
  ```
-
- Remove specific kernels. You can use wildcards to remove many kernel versions with one command.
- ```bash
  sudo apt purge linux-image-<rest of the name>
  ```
- Please remember to run
- ```Bash
  sudo update-grub
  ```
